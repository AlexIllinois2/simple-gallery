## 内联 Simple-Commons（移除外部 submodel 依赖）

- 原仓库通过 JitPack 依赖 `com.github.SimpleMobileTools:Simple-Commons:ea86877113`（仅在本地 m2 镜像 / gradle 缓存里有 AAR，无源码）。
- 处理：从 GitHub 拉取该提交源码，落地为仓库内模块 `commons/`（693 个文件，含 `schemas/` Room schema），`settings.gradle.kts` 增加 `include(":commons")`，`app` 改为 `implementation(project(":commons"))`，`gradle/libs.versions.toml` 删除 simple-commons 条目并补齐 commons 所需依赖/插件（compose、lifecycle、joda-time、gson、ez-vcard、patternLockView、reprint、fastscroller、rtl-viewpager、kotlinx-serialization 等）。
- 关键：原工程 AGP 7.4.0 + Kotlin 1.8.22 无法 dex 含 Kotlin 1.9 metadata 的 commons AAR（`ERROR:D8: com.android.tools.r8.kotlin.H`，基线构建本来就失败）。因此把工具链升到 **AGP 8.1.2 + Kotlin 1.9.10 + KSP 1.9.10-1.0.13**，对齐 commons 上游；根 `build.gradle.kts` 增加 androidLibrary / parcelize / kotlinSerialization 插件别名（`.apply(false)`），否则子模块 `alias()` 会报 “already on the classpath with an unknown version”。
- 验证：`:app:assembleFossDebug` 与 `:app:assembleFossRelease`（R8）均成功；依赖图只剩 `project :commons`。
- `commons/.gitignore` 写 `/build`，避免把 100MB 构建产物加进仓库。
